# Fire Risk Systems — Android Pilot

This repository contains the Flutter **Android pilot** source bundle and GitHub Actions APK build configuration. It is a development build, not a production fire-safety application.

**Privacy:** This GitHub repository is currently PUBLIC. Change it to **Private** under Settings → General → Danger Zone before adding any proprietary documents, real customer records, credentials or production configuration.

The app requires the separately supplied Fire Risk Systems backend to operate. No client checklists or customer data are bundled. Android debug APKs are for internal testing only.

Once the build workflow succeeds, download the `Fire_Risk_Systems_Demo_APK` artifact from Actions.
